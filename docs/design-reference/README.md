# Client Design References

These screenshots are taken from the client's Canva website concept.

They establish the desired visual direction.

They should inform:

- colour
- typography character
- image treatment
- section rhythm
- whitespace
- rounded geometry
- dark/light alternation
- asymmetric editorial composition

They should NOT be interpreted as:

- exact responsive specifications
- required pixel positions
- browser chrome
- production navigation behaviour
- accessibility semantics
- final content architecture
